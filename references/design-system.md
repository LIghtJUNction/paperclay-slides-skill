# Paperclay Slides 设计规范

## 视觉原则

用暖纸底色、深墨文字和大面积留白形成阅读秩序。陶土橙负责引导视线，浅蓝、桃色、灰米和鼠尾草绿帮助区分并列内容。主要信息依靠位置、字重和尺度区分，装饰保持克制。

本规范来自对用户提供的栅格路演 PDF 的视觉提炼。表中的颜色是本模板采用的重建值，字体是可公开取得的视觉近似，具体来源见 [provenance.md](provenance.md)。

## 色彩

机器可读值保存在 `assets/tokens.json`。避免在正文生成过程中临时添加接近但不同的颜色。

| Token | 色值 | 用途 |
| --- | --- | --- |
| `paper` | `#F6F2EC` | 常规页面背景 |
| `ink` | `#0A0A09` | 标题、正文、重点数字 |
| `muted` | `#77756E` | 次要说明与辅助文字 |
| `clay` | `#E07852` | 主强调、分组和图表重点 |
| `orange` | `#DB6840` | 细条与更集中的强调区域 |
| `blue` | `#BED2E4` | 浅蓝分组背景 |
| `peach` | `#EDC9B6` | 桃色分组背景 |
| `stone` | `#E4E1D5` | 中性区域和占位底色 |
| `white` | `#FAF9F6` | 暖白内容面 |
| `sage` | `#CED5C1` | 辅助分类背景 |
| `teal` | `#62A08F` | 图表的辅助序列 |
| `line` | `#C8C5BC` | 细分隔线 |
| `dark` | `#121211` | 深色分节页背景 |

在浅色块上使用深墨文字。深色分节页使用浅色文字。让同一个颜色在相邻页面保持相同含义，避免把强调色同时用于多个无关结论。

## 页面网格

设计坐标使用 1280 × 720 的 16:9 画布。`layouts.json` 的 `bounds` 和 `font_px` 都以该画布为基准；修改坐标时保持同一单位体系。

| 项目 | 设计值 | 说明 |
| --- | --- | --- |
| 常规左右边距 | 64 | 正文可用宽度 1152 |
| 章节提示起点 | y = 29 | 小号页眉，存在于常规内容页 |
| 页面标题起点 | y = 63 | 标题区域通常保留两行空间 |
| 主内容起点 | y = 194 | 图表、表格、分栏从此处展开 |
| 页脚起点 | y = 677 | 左侧组织名，右侧页码 |
| 左图章节页图片宽度 | 398 | 图片覆盖整页高度 |
| 左图章节页文字起点 | x = 480 | 与左侧图片形成清楚间隔 |

封面和章节页按各自版式布局。满版图片可以越过常规正文边距，但标题和正文仍需对齐已有的文字轴线。

## 字体与层级

正文和多数标题使用 `Noto Sans CJK SC`。章节导语、部分导航使用 `Noto Serif CJK SC`，用于营造纸面阅读感。字体文件单独从官方 Noto CJK 项目安装。

| 场景 | 典型字号 `font_px` |
| --- | --- |
| 封面标题 | 68 |
| 左图章节标题 | 60 |
| 深色分节标题 | 76 |
| 常规页面标题 | 40 |
| 分组标题 | 24–28 |
| 正文 | 22–24 |
| 注释与图表说明 | 15–18 |
| 页眉 / 页脚 | 14 / 12 |

上表是模板设计坐标中的字号。PowerPoint 界面通常以 pt 显示字号，实际文件保留导出时的换算。编辑时以对应占位符的现有字号为准，不将设计坐标值直接当成 pt 覆盖。

按字段的 `max_chars` 控制文字数量，并为较长英文单词、中文标点和手动换行保留余量。字符计数与真实排版宽度不同，最终以渲染结果判断是否合适。

| `trend` | 左侧指标与右侧趋势 | 两项指标配趋势图 |

## 内容密度

每页围绕一个主题组织内容。比较页先保持两列信息对等，图表页先保证坐标、单位和图例清楚，附录页容纳较长解释。

文字超出字段限制时，先删除重复信息，再检查版式是否合适。例如，两段较长解释适合 `appendix_text`；需要详细图注的证据适合 `chart_full`。仍然过密时拆成两页，保持相同的章节标签。

模板内的彩色区域承担分组作用。保持既有间距，不在空白处补充装饰图标、渐变、阴影或没有信息用途的小卡片。

## 图像与数据

图片优先选用有明确主体、构图简洁的素材。`cover` 裁切适合满幅照片，`contain` 保留整个图像，适合截图、标识或需要看全的示意图。检查人物面部、文字和关键设备是否被裁掉。

表格保留表头、单位和数据口径，优先使用少量横向分隔线。图表保留真实数值和来源，不将图形装饰成缺乏可读刻度的背景。并列图表采用一致单位；需要比较绝对大小时，还需核对各图坐标范围。
